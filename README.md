# empresa-finpay

## Setor
FinTech / Pagamentos Digitais

## Contexto do problema
A FinPay cresceu rapidamente e integrou novos canais de pagamento (cartão, PIX e boleto), mas a API pública ficou sem documentação adequada. Times internos e parceiros externos relatam dúvidas sobre autenticação, contratos de payload, códigos de erro e versionamento.

## Objetivo do desafio
Produzir uma documentação de API clara, padronizada e útil para consumidores internos e externos, reduzindo ambiguidades de integração.

## Instruções resumidas para os grupos
1. Faça um fork deste repositório para a conta do grupo.
2. Trabalhe exclusivamente no fork do grupo.
3. Preencha a documentação na pasta `docs/`, usando `docs/api-template.md` como referência e consolidando o resultado em `docs/api.md`.
4. Entregue o link do fork do grupo conforme orientação da disciplina.
