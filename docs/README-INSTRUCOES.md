# Instruções da Atividade

Este repositório faz parte da atividade prática da disciplina de **Documentação Técnica em DevOps**.

## Objetivo do grupo
Estruturar uma documentação de API profissional para o estudo de caso da FinPay, com foco em consumo por times de desenvolvimento, QA, operações e parceiros de integração.

## Documentação que deve ser produzida
- Arquivo final: `docs/api.md`
- Referência de estrutura: `docs/api-template.md`

## Regras da simulação
- Esta atividade é uma simulação acadêmica.
- Não é necessário implementar funcionalidades nem alterar arquitetura real de software.
- O foco é exclusivamente qualidade de documentação técnica.

## Forma de trabalho
- O trabalho deve ser realizado no fork do grupo.
- Recomenda-se versionar as melhorias de documentação em commits pequenos e descritivos.
